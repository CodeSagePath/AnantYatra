AnantYatra trip-planner prototype demo

Demo scenario

- Start: Bengaluru
- Destination: Mangaluru
- Duration: 3 days
- Mode: Car
- Travelers: 2
- Daily driving limit: 7 hours
- Interests: nature, heritage
- Overnight stays: enabled

Start locally

1. Start the Valhalla container. This machine's local service is available at
   http://127.0.0.1:5006/status.
2. In the server directory, run:

       ROUTING_HOST=http://127.0.0.1:5006 npm run dev

3. In the client directory, run:

       VITE_API_URL=http://localhost:5000/api npm run dev

4. Open http://127.0.0.1:5173/ and enter Bengaluru and Mangaluru as the start
   and destination. Calculate the route, then open “Build a day-by-day trip
   plan”. Enter the demo constraints above and create the draft.

What to explain

The route and place candidates come from local routing/map data. The planner
uses those supplied facts and application rules to form a draft, validate
daily route legs, and expose unknowns. The Qwen adapter was trained on POI fact
lookup examples; it does not choose itinerary stops in this demo. The current
itinerary baseline is deterministic.

Limitations to state

- The local place snapshot may be incomplete, stale, or unverified.
- Facility details, opening hours, traffic, weather, road closures, and
  on-road safety are not confirmed by this draft.
- Route times are estimates from the configured routing snapshot.
- The plan is a draft and needs traveler review.
